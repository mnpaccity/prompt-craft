# Prompt CRAFT

An interactive web app for learning and memorizing the **CRAFT** prompting method — **C**ontext, **R**ole, **A**ction, **F**ormat, **T**one — plus a library of ready-to-use prompts and handy tools.

## What's inside
- **🏠 Home** – the CRAFT method, a step-by-step "put it together" example, a sample result with animated example clips (music + voiceover), and start-to-finish video-making guides
- **🎮 Games** – Letter Match, Which Letter?, Word Scramble, Prompt Builder, Memory Test
- **📚 Prompt Library** – home, office, problem solvers, business strategy, local lead gen (incl. cold-calling script), video creation, conflict resolution
- **🏡 Real Estate** – Photo-to-Video Studio (per-photo AI video prompts with professional camera, lens, lighting and transition options, ZIP/paste/listing-link photo import, stitching plan, live preview), real estate prompts & intro scripts, and **🔍 Video Detective** (upload a video, screen recording or screenshots and get a best-guess breakdown of the prompts used)
- **🧮 Tools** – calculator, running receipt, mortgage and auto loan calculators
- **📅 Planner** – calendar, to-dos, Google Calendar sync (inside claude.ai), Apple Calendar setup guide
- **👤 My Info** – autofill your details into prompts (saved only in your browser)
- **🎓 Skill level** – Just starting / Not completely lost / I got this changes the games' difficulty, prompt detail (PLUS and PRO versions), tool tips and help instructions across the whole site

## How to use
Open `index.html` in any web browser. Everything runs in a single file — no install needed.

> Live Google Calendar sync works when the page is opened as an artifact inside claude.ai with the Google Calendar connector enabled. Everywhere else, the planner uses "Add to Google Calendar" links.

- **💾 My Files** — save prompts, video plans, video breakdowns, how-to guides, photos, documents and your own videos to a personal folder; edit, search, copy, download (single files or everything as a .zip) and sync them to your Claude account.
- **⌨️ Claude Code cheat sheet** — button in the toolbar with 300+ Claude Code commands, terminal commands, flags and keyboard shortcuts; search, copy, save or download.
- **🌳 Pro Missions** — advanced multi-step projects (marketing campaign, listing launch, client pitch, team retreat, crisis response) with live coaching and completeness grading.
